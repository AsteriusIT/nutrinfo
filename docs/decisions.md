# Décisions du projet

| # | Sujet | Décision | Conséquences |
|---|---|---|---|
| D1 | **Stack technique** | HTML5 + **Tailwind CSS v4** + **React Router v8 (mode framework)** sur Vite, TypeScript | Pages **pré‑rendues (SSG)** via `prerender` de React Router → HTML statique, bon SEO, hébergement statique gratuit (GitHub Pages, Netlify, Cloudflare Pages). Hydratation React uniquement pour les outils interactifs. Contenus en **MDX** (pages) et **JSON/YAML** (fiches). |
| D2 | **Relecture scientifique** | Pas d'expert pour l'instant ; proposé plus tard | Chaque contenu porte un statut `relecture: "non-relu" \| "relu"` et une date. Bandeau discret « Contenu en attente de relecture par un professionnel ». Chiffres toujours sourcés. |
| D3 | **Données alimentaires** | Méthodes **françaises et européennes** | Composition : **CIQUAL (ANSES)** — Licence Ouverte Etalab 2.0 (attribution requise). Références nutritionnelles : **ANSES** en priorité, **EFSA DRV** en complément. Énergie : formule de **Black et al. 1996** (France) avec **Henry 2005** (EFSA) en option. Impact environnemental : **Agribalyse (ADEME)**. Étiquetage : **règlement UE INCO 1169/2011**, Nutri‑Score. |
| D4 | **Illustrations** | Simples mais centrales ; sources ouvertes | Voir [illustrations.md](illustrations.md) : style maison géométrique « en carrés » + icônes **CC0** (Healthicons). |
| D5 | **Marque / licence** | Pas de marque ; **domaine public** | Contenus éditoriaux et illustrations maison sous **CC0 1.0**. Code sous **CC0** (ou Unlicense). Les données tierces gardent leur licence (CIQUAL : mention de la source obligatoire). Nom du site : « nutrinfo ». |
| D6 | **Types de contenu** | 2 types : **page plein contenu** et **cartes d'information** | Voir [modele-contenu.md](modele-contenu.md). |
| D7 | **Design** | Formes **carrées** (inspiration mistral.ai), coloré, épuré, bonnes pratiques. **Révisé le 2 novembre 2026 :** arrondis doux sur l'interface (boutons, cartes, panneaux), éléments graphiques toujours carrés | Voir [design-system.md](design-system.md). |
| D8 | **Assistant IA** | Questions-réponses avec **Claude** (API Anthropic) via un **Worker Cloudflare** qui sert aussi le site statique | Le modèle tourne chez Anthropic, le Worker garde la clé et le prompt. L'assistant ne répond qu'à partir des contenus du site (corpus généré au build par `scripts/build-corpus.mjs`, mis en cache côté API). Garde-fous : pas de conseil médical, liens vers les pages, 10 questions/min/IP, même origine uniquement, conversations non journalisées. Code : `worker/`, `app/components/chat-assistant.tsx`. |
| D9 | **Thème sombre** | Suit le réglage du système ; bouton dans l'en-tête pour forcer clair ou sombre (gardé dans `localStorage`) | Palette en `light-dark()` dans `app/app.css` (contrastes AA vérifiés). `ink`/`white` s'inversent ; `dark`/`light` sont fixes (texte sur les aplats 500, bocal à sucre). Les aplats 500 sont identiques dans les deux thèmes. |
| D10 | **RGPD** | Page `/confidentialite` ; aucune requête vers des tiers hors assistant | Fraunces servie par le site (`@fontsource-variable/fraunces`) au lieu de Google Fonts. Responsable et contact **à compléter** dans `app/routes/confidentialite.tsx` avant la mise en ligne. |
| D11 | **Publication GitHub Pages** | Build statique sans assistant (`npm run build:pages`), publié par GitHub Actions | Options de build dans `app/lib/config.ts` (`VITE_ASSISTANT`, `VITE_HEBERGEUR`) et `BASE_PATH` (sous-chemin du dépôt). `scripts/pages-postbuild.mjs` recompose la racine du site dans `build/pages/`, ajoute `404.html` (coquille SPA → page introuvable) et `.nojekyll`. Le Worker Cloudflare (D8) reste possible en parallèle. |
| D12 | **Navigation par rubriques** | 3 menus déroulants (Apprendre, Bien manger, Selon mon âge) au lieu de liens à plat ; plan du site dans le pied de page | Source unique `app/lib/navigation.ts`. Panneaux ouverts au clic (clavier, tactile), fermés par Échap, clic extérieur ou changement de page. Une nouvelle rubrique = un objet de plus. |
| D13 | **Fiches « Apprendre les bases »** | 8 fiches (protéines, glucides, lipides, fibres, eau, vitamines, minéraux, énergie), parcours numéroté | Contenu dans `content/fiches/bases.yaml`, une seule route `apprendre/:id` pré-rendue d'après le YAML. Gabarit fixe : question, image pour comprendre, rôles, sortes, sources alimentaires, chiffre sourcé, kcal par gramme, idée reçue. Sources ajoutées : ANSES 2011 (acides gras), règlement UE 1169/2011. |
| D14 | **Règle des 3 couleurs** | Interface en fond + encre + un seul accent vert (60 / 30 / 10) ; les graphiques gardent les 3 couleurs de l'assiette (vert, jaune, rose) | Tokens `accent-100/500/800` dans `app/app.css`. En-têtes de page en gris clair, étiquettes, menus, cartes et encadrés en encre et accent. Bande de pixels en accent seul. Eau et produits laitiers en neutre dans l'assiette, verres d'eau en encre. Remplace le codage « une couleur par rubrique » de D7. |
