## Abréviations utilisées

- **AET** : apport énergétique total
- **BNM** : besoin nutritionnel moyen
- **RNP** : référence nutritionnelle pour la population (couvre ~97,5 % des personnes)
- **AS** : apport satisfaisant (quand les données ne permettent pas d'établir un BNM)
- **LSS** : limite supérieure de sécurité
- **AGS / AGMI / AGPI** : acides gras saturés / mono‑ / polyinsaturés

## Points de vigilance

- Les valeurs chiffrées des synthèses ont été reprises des documents ci‑dessus et des connaissances établies ; **avant publication, chaque valeur doit être relue contre le PDF source** (tableaux ANSES 2021 notamment).
- Le PNNS 5 (avril 2026) reprend les repères du PNNS 4. La mention explicite « limiter les produits ultra‑transformés » a fait débat lors de sa rédaction : présenter ce sujet avec nuance.
